### 💫 About Me

I'm a Fullstack Web Developer based in Bandung, Indonesia, with hands-on experience
building scalable web applications using **React** on the frontend and **Golang (Gin)**
on the backend. I enjoy designing clean RESTful APIs, integrating PostgreSQL/Redis,
and shipping responsive, maintainable UIs. Alongside client work, I also create
tech-education content in Bahasa Indonesia for the developer community.

- 🔭 Currently building **Finvera**, a personal finance & bookkeeping web app
- 🌱 Deepening my skills in Clean Architecture, gRPC, and system design
- 📚 Sharing developer tips & tricks through LinkedIn carousel content
- 📍 Based in Bandung, Indonesia
